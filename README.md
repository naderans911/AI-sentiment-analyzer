# Simple AI Sentiment Analyzer

A small Python NLP project that analyzes the sentiment of text and classifies it as **Positive**, **Negative**, or **Neutral**.

The project uses the VADER sentiment-analysis library and demonstrates basic natural-language processing in Python.

## Features

- Analyze sentences entered by the user
- Classify text as Positive, Negative, or Neutral
- Display a compound sentiment score
- Simple command-line interface
- Lightweight and easy to run

## Example

```text
Enter text: I really enjoyed this project!

Sentiment: Positive
Confidence score: 0.669
```

## Installation

Make sure Python 3.9+ is installed.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/simple-ai-sentiment-analyzer.git
cd simple-ai-sentiment-analyzer
```

Install the dependency:

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

Type `quit` when you want to exit.
